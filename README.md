# Salinex AI Project (MVP)
## سیستم هوشمند مدیریت و بازیافت پسماند آب‌های شور

این پروژه با هدف بهینه‌سازی استخراج املاح باارزش (مانند لیتیوم و منیزیم) از پساب‌های صنعتی و آب‌های شور طراحی شده است.

### قابلیت‌های فاز ۱:
- تشخیص خودکار نوع Brine بر اساس آنالیز شیمیایی.
- داشبورد پایش داده‌ها با استفاده از Streamlit.
- ساختار پوشه‌بندی استاندارد برای پروژه‌های صنعتی AI.

### نحوه اجرا:
1. فعال‌سازی محیط: `conda activate salinex`
2. اجرای داشبورد: `streamlit run app.py`
